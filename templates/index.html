ℹ️ About SocialMind

An ethical, AI-powered social media assistant built on IBM Granite LLM

🚀 Features
  • ✍️ Content Generator — AI posts, captions, hashtags for any platform
  • 📅 Campaign Planner — Full strategy + 2-week content calendar
  • 📈 Trend Analyzer — Industry trends with [PREDICTED] labels
  • 💬 AI Chatbot — Context-aware social media Q&A assistant
  • 📊 Analytics Dashboard — Engagement, sentiment, hashtag performance
  • 🏷️ Hashtag Engine — Platform + goal + industry optimised tags
  • 📆 Content Calendar — Automated posting schedule generator
  • ⚖️ BMI for Posts — Engagement estimation before publishing
🛡️ Ethical AI Guardrails
  • 🔍 Input Safety — All user inputs scanned for harmful content
  • 🔍 Output Safety — All AI outputs validated before display
  • ✅ Human Approval — Posts require approval before publishing
  • 🏷️ Prediction Labels — AI predictions clearly marked [PREDICTED]
  • 🔒 Data Privacy — No user data stored beyond session
  • ⚠️ HAM Principles — Helpful, Accurate, Mindful in every response
  • 🚫 Content Blocking — Hate speech, spam, deception auto-blocked
  • 📋 Disclaimer — AI-generated label on all content
