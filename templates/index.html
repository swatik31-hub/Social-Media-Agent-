🛡️ Ethical AI Guardrails & Data Privacy
🔍

Input Safety Screening

Every user input is scanned against harmful content patterns including hate speech, spam, deception, misinformation, and harassment before reaching the AI model. Harmful inputs are blocked immediately with a clear message.

✅

Output Validation & Human Approval

All AI-generated content is validated for safety before display. Generated posts are held in a "pending approval" state — a unique post ID is issued and humans must explicitly approve or reject content before it can be published anywhere.

🏷️

Transparent Prediction Labelling

All AI-predicted trends are clearly labelled [PREDICTED] to distinguish them from established, verified trends labelled [TREND]. This prevents over-reliance on unverified AI predictions. Engagement estimates include explicit disclaimers.

🔒

Data Privacy — Session-Only Processing

No user data, brand details, or generated content is stored in any database. All data exists only for the duration of the session. Uploaded images are processed in-browser only. No third-party data sharing occurs.

⚖️

HAM Principles (Helpful, Accurate, Mindful)

All AI prompts are engineered with HAM principles: content must be Helpful (actionable and relevant), Accurate (factually grounded, no fabrication), and Mindful (culturally sensitive, inclusive, non-manipulative). System prompts explicitly prohibit harmful, deceptive, or unethical advice.

🚫

Content Category Blocking

Seven categories are permanently blocked: hate speech / discrimination, misinformation / deepfakes, spam / phishing / clickbait, threats / harassment / bullying, explicit / NSFW content, plagiarism / copyright infringement, and manipulative / deceptive messaging.

📋

Mandatory AI Disclosure

Every piece of AI-generated content carries a visible disclaimer: "This content is AI-generated for informational and creative purposes. Always review AI-generated posts before publishing." This ensures users maintain accountability for their published content.

🔐

Secure API Integration

IBM watsonx.ai API credentials are stored server-side only, never exposed to the client browser. All API calls use HTTPS. Input payloads are sanitised before transmission. The backend follows least-privilege principles.
